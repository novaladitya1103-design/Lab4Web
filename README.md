## 🚀 Langkah-Langkah Praktikum

1. **Membuat Struktur Folder & File Dasar**
* Membuat folder utama bernama `lab4_layout`.
* Membuat file `home.html` dan `style.css` di dalamnya.


2. **Pengaturan Reset CSS & Kontainer Utama**
* Menerapkan *Reset CSS* untuk membersihkan margin dan padding bawaan browser.
* Mengatur lebar kontainer utama (`#container`) sebesar `980px` dengan posisi di tengah layar (`margin: 0 auto`) serta efek bayangan (*box-shadow*).


3. **Membuat Menu Navigasi**
* Menambahkan elemen `<nav>` dengan daftar menu: **Home**, **Artikel**, **About**, dan **Kontak**.
* Memberikan efek interaktif berupa perubahan warna latar belakang saat kursor diarahkan (*hover*) atau pada menu aktif (`.active`).


4. **Membuat Bagian Hero & Konten Utama (Home)**
* Menambahkan section *hero* sebagai banner utama penyambut pengunjung.
* Membuat tata letak konten utama (`#main`) yang berisi grid kotak (*box*) serta artikel fitur pendukung.
* Menambahkan area samping (`#sidebar`) yang berisi widget tautan dan teks.


5. **Menambahkan Halaman Tambahan (About & Kontak)**
* **`about.html`:** Berisi informasi deskripsi/profil serta daftar portofolio singkat.
* **`kontak.html`:** Dilengkapi dengan formulir interaktif (*form input*) yang mencakup kolom Nama Lengkap, Email, dan Pesan (*Message*).
